# Security Policy

We take the security of MindCare AI seriously. This document outlines our policy regarding supported versions, responsible disclosures, and instructions on how to report vulnerabilities.

## Supported Versions

Only the latest major version receives security updates.

| Version | Supported |
| ------- | --------- |
| 2.0.x   | Yes       |
| 1.x.x   | No        |

## Reporting a Vulnerability

If you find a security vulnerability, please do **not** open a public issue. Instead, report it privately through the following process:

1. Send an email to **security@mindcare.ai**.
2. Include a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept code or payloads.
3. We will acknowledge receipt of your report within 48 hours and work to resolve the issue as quickly as possible.

## Responsible Disclosure

To protect our users and system integrity, we ask that you:
- Do not exploit the vulnerability (e.g., download more data than necessary to demonstrate the issue, delete or modify records).
- Provide us a reasonable period to investigate and remediate the issue before disclosing it publicly.
- Do not perform DDoS attacks or physical security checks against our endpoints.
