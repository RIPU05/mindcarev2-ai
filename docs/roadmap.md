# Architecture Roadmap

## Completed Foundation

- Legacy archive under `legacy/`.
- Monorepo shape with frontend and backend workspaces.
- FastAPI foundation and route modules.
- Pydantic schemas and enums.
- Next.js app scaffold, route groups, providers, and theme architecture.

## Next Architecture Work

- Repository and unit-of-work interfaces.
- Queue and worker boundary contracts.
- Storage adapter interfaces for media.
- Observability and audit-event contracts.
- Test architecture for API contracts and frontend API client behavior.

## Future Implementation Work

- Authentication and authorization.
- Supabase integration and migrations.
- AI provider adapters and safety policies.
- Product screens and form flows.
- Dashboard aggregation and cache refresh jobs.
